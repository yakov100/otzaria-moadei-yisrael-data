# מאגר מועדי ישראל

הצד הפומבי של תוסף **מועדי ישראל** לאוצריא: קובץ המאגר המרכזי, ומסמכי הלימוד
שהתוסף מפנה אליהם.

התוסף עצמו נמצא ב-[otzaria-moadei-yisrael](https://github.com/yakov100/otzaria-moadei-yisrael).

## מה יש כאן

```
moadim.json      המאגר המרכזי — מועדים, קבוצות תוכן, סוגי תוכן ומקורות
docs/<מועד>/     מסמכי לימוד, מסודרים לפי מועד
```

`moadim.json` הוא מה שהתוסף מוריד. הוא מחליף את המאגר המצורף רק אם הוא תקין
במבנה ו-`revision` שלו חדש יותר, כך שקובץ פגום אינו מוחק תוכן שהמשתמש כבר קיבל.
`revision` הוא תאריך `YYYY-MM-DD` — צורה שגדלה לקסיקוגרפית מעצמה.

## המסמכים

השיעורים כאן הם מתוך **גמ״ח אוצר התורה**, ומפורסמים כאן ברשות. הם נכתבו על ידי:

| | |
|---|---|
| הרב יצחק מרדכי רובין | ימים נוראים, פסח, סוכות, חנוכה, פורים, בין המצרים, ספירת העומר |
| הרב צבי ובר | הלכות חול המועד, תקיעת שופר, חנוכה |
| הרב יעקב דומב | הלכות פורים |
| הרב מאיר קאופמן | נר שבת וחנוכה |
| דרשו | הלכות פסח |
| הרב אריאב עוזר | עיון בסוגיות המועדים: סוכות, פסח, חנוכה, פורים, זכור, ראש חודש, חול המועד ועוד |

הזכויות נשארות של הכותבים. מי שמבקש להסיר חומר או לתקן ייחוס — לפתוח issue,
והוא יוסר.

**מה שאין כאן בכוונה:** ספרים שכבר קיימים בספריית אוצריא. התוסף מפנה אליהם
במקומם ואינו משכפל אותם — זה מה שמשאיר אותו קטן, מהיר, ועובד גם בלי אינטרנט.
מכאן שגם ש״ס, שולחן ערוך וספרי יסוד אינם כאן; הם נפתחים ישירות באוצריא.

## למה כאן ולא בדרייב

גוגל דרייב חסום בסינון נטפרי — גם דף השיתוף וגם נקודת ההורדה הישירה. קהל
המשתמשים של אוצריא חופף לכך במידה רבה, ומאגר מסמכים בדרייב פירושו שכבת תוכן
שלמה שאינה קיימת עבור חלק ניכר מהם. GitHub עובר.

## הקובץ חייב להישאר קטן — וזו אזהרה תפעולית

`moadim.json` **נשמר מוקטן** (בלי רווחים מיותרים), וזה אילוץ ולא נוחות.

סינון נטפרי סורק קובץ שעובר סף גודל, חוסם אותו, ו**שומר את ההחלטה על
הכתובת**. הקובץ נקרא בעבר `catalog.json`; כשהוא היה 228KB הוא נחסם, והקטנתו
ל-181KB **לא שחררה אותו** — אותו תוכן בדיוק, בשם `moadim.json`, הוגש במלואו.

כלומר: **חריגה אחת מהסף פוסלת את הכתובת לתמיד**, ואי אפשר לתקן אותה בדיעבד
אלא בהחלפת שם — ושם חדש פירושו שכל המשתמשים הקיימים מצביעים לכתובת מתה.

מכאן שני כללים:

1. לבדוק את גודל הקובץ לפני כל פרסום. הסף שנמדד הוא סביב 220KB; המרווח היום
   הוא כ-40KB.
2. כשהמאגר יתקרב לסף — לפצל אותו (קובץ אינדקס וקובץ לכל מועד), ולא להקטין
   עוד. הקטנה קונה זמן; פיצול פותר.

## למה המסמכים אינם נמשכים אוטומטית

הסינון חוסם הורדת PDF ו-DOCX (`warning-file-distorted`), ולכן התוסף אינו
מוריד מסמכים בעצמו. הוא פותח אותם בדפדפן דרך `app.openUrl`, ושם המשתמש רואה
את דף האזהרה של הסינון ויכול להמשיך. זו הסיבה ש-§10 — עותק מקומי אוטומטי —
אינו ממומש: לא מגבלה של ה-SDK, אלא של הרשת שבה המשתמשים יושבים.

## גישת רשת

התוסף ניגש לכאן דרך `network.fetchStream`, ולכן הכתובת חייבת להופיע גם
ב-`network.allowlist` של המניפסט וגם ב-`plugin_network_allowlist.txt` שבענף
`dev` של אוצריא. שתי הרשימות נדרשות; אחת בלי השנייה מחזירה 403 בזמן ריצה.
